# WordWake — public contributor baseline candidate

WordWake is an original short letter-path game intended for later, separately authorized integration into Yawrd. Connect neighboring letters into authored words, with no overlap and every cell used exactly once. Deliver three original handcrafted puzzles collectively covering Yawrd, Keelbase, NEAR, Web3, agents and building together. Private source is unnecessary; Keelbase is only a puzzle theme.

Founder-approved contract ww-v1 uses eight-neighbor adjacency, exact authored ordered answer paths, deterministic next-cell hints, selection-first undo and restart to initial state. The frozen specification and validation guidance are in SKILL.md, with data in CONTRACT_FIXTURES.json. Contract-example data does not count toward the three original puzzles.

T1 owns the pure TypeScript engine, one reference puzzle and engine tests. T2 owns the React player, two additional puzzles, its scripted test double, independent manifest checker and experience tests. Both use the same frozen types and fixtures without importing unfinished work from the other. TASKS.json preserves the reviewed task definitions and unresolved activation fields.

Require accessible phone/desktop play, answer checking, hints, undo and restart; measure the few-minute session goal through later playtesting. Final acceptance combines the real engine, player and three puzzles, automated tests, manifest checks, phone/desktop evidence, originality/theme review and founder technical review through GitHub. Fixture/test-double checks alone cannot establish game acceptance.

The founder approved the defaults and T1/T2 split on 2026-11-13 and is the initial technical reviewer and contribution acceptor. This public derivative omits private source records. Approval does not activate tasks, settle rewards or authorize public publication, host integration, funding or deployment. Repository URL/SHA, contributors, branch/review routing and installation permission must be supplied separately. See README.md and PUBLIC_REVIEW.json for baseline guidance and integrity binding.
